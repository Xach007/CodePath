# ADVANCED CODE EDITOR

Implement a powerful interactive code editor using Monaco Editor (the same editor used in VS Code).

Features required:

- syntax highlighting
- autocomplete
- line numbers
- error highlighting
- dark/light theme
- run button
- reset code button

When the user clicks "Run Code":

1. Send the code to the backend via AJAX.
2. Execute the code safely in a sandbox environment.
3. Validate it against predefined test cases.
4. Return:

- pass/fail
- output
- expected output
- hint message if failed

If the user passes all tests, mark the lesson as completed and unlock the next lesson.

The editor must work smoothly on desktop and mobile.
