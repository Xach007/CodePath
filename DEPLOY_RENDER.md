# CodePath hosting on Render

This project is prepared for Render hosting with `render.yaml`.

## What Render will create

- Web service: `codepath`
- PostgreSQL database: `codepath-db`
- Production domain: `https://codepath.ru`

## Deploy

1. Push this repository to GitHub.
2. Open Render Dashboard.
3. Create a new Blueprint from the GitHub repository.
4. Render will read `render.yaml` from the repository root.
5. Start the Blueprint deploy.

The service build command will install dependencies, build the frontend, build the API server, and start:

```sh
node artifacts/api-server/dist/index.cjs
```

## Domain

After the service is created, open the service in Render and verify the custom domain `codepath.ru`.

In the domain DNS panel, point `codepath.ru` to the Render target shown in the Custom Domains section. Render usually shows the exact DNS record to add. After DNS propagation, Render will issue HTTPS automatically.

Useful Render docs:

- Blueprint YAML: https://render.com/docs/blueprint-spec
- Custom domains: https://render.com/docs/custom-domains
- DNS setup: https://render.com/docs/configure-other-dns

## Optional environment variables

These are already configured in `render.yaml`:

- `NODE_ENV=production`
- `APP_BASE_URL=https://codepath.ru`
- `SESSION_SECRET` generated by Render
- `SUPPORT_EMAIL_TO=krokodil22009@gmail.com`
- `DATABASE_URL` from `codepath-db`

Add these in Render only if needed:

- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_USER`
- `SMTP_PASS`
- `SMTP_FROM`
- `SMTP_SECURE`

Google OAuth callback URL:

```text
https://codepath.ru/api/auth/google/callback
```
